# jogo-da-velha
tic tac toe em C

Implementação simples de um jogo da velha, feita como um exercicio em C.

- Dois jogadores alteram entre 'x' e 'o'
- Em cada rodada, o jogador escolhe a linha e a coluna (de 1 a 3) onde quer jogar.
- O jogo detecta automaticamente vitória (linha, coluna ou diagonal) ou empate.
